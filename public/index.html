Botni ishga tushirish tartibi
  1. @BotFather dan bot tokenini oling va pastdagi maydonga kiriting.
  2. Botni ulash / webhook o‘rnatish tugmasini bosing — sozlamalar saqlanib, webhook ulanadi.
  3. Holat bo‘limidagi bot havolasini ochib, Telegramda botga /start yuboring.
  4. Bot qaytargan raqamli ID ni avval Ega/Admin Telegram ID maydoniga kiriting. Xodimlar jadvalida egasining qatoriga ham shu ID ni yozib, saqlang.

Eslatma: Yangi deploydan keyin webhookni shu sahifadagi “Saqlash va botni ulash” tugmasi bilan yangilang. Telegram ID olish uchun ulangan botga /start yuboring.
